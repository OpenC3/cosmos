The release workflow (.github/workflows/release.yml) builds and publishes the
openc3 package to PyPI. To do it by hand, build from a fresh clone of the
release tag, not a working tree: uv build ships every file under openc3/,
including untracked and gitignored ones.

git clone --depth 1 --branch v<version> https://github.com/OpenC3/cosmos.git
cd cosmos/openc3/python
uv build
uv publish

See https://docs.astral.sh/uv/guides/package/ for building and publishing.
