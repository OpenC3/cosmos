Security Vulnerabilities

Below is a list of CVEs reported in COSMOS. This does not include CVEs in our dependencies - you can find those in our Trivy scans.

Publishing CVEs

Due to the recent rise in submitted CVEs, Github has fallen behind in issuing and publishing CVEs. Thus some of these URLs may not yet resolve in the database even though they have been assigned.
